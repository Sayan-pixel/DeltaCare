Executive Abstract

Accurate, transparent actuarial pricing is a foundational challenge in computational healthcare economics. Traditional consumer health insurance quoting portals suffer from severe informational asymmetry, predatory personal data harvesting, and black-box underwriting algorithms. In this project, we design, implement, and rigorously evaluate DeltaCare, a machine learning system that provides instantaneous, statistically robust health insurance premium predictions while illuminating the financial impact of controllable lifestyle choices (e.g., smoking cessation and BMI management).

Using the standard empirical US Medical Cost Personal Dataset (N = 1,338 records), we formulate the problem as a supervised continuous regression task. We conduct rigorous statistical dependency and correlation analyses, demonstrating that standard linear models (Ordinary Least Squares, Ridge Regression) suffer from structural underfitting (R2 ≈ 0.78, MAE ≈ 4,181 USD) due to a massive, non-linear interaction effect between bmi and smoker. To overcome these limitations without resorting to opaque, heavy native ensemble libraries (e.g., XGBoost), we deploy a regularized Classification and Regression Tree (CART) regressor utilizing an L1 absolute error loss criterion (criterion="absolute_error"), constrained tree depth (max_depth=6), and an actuarial support floor (min_samples_leaf=10).

Our proposed architecture achieves a holdout Coefficient of Determination of R2 = 0.8692 (exceeding the course benchmark gate of ≥ 0.85) and a Mean Absolute Error of MAE = 1,749.60 USD (well below the ≤ 2,000.00 USD requirement), while reducing serialized artifact size by >95% (to 11.0 KB). Crucially, we introduce an automated domain monotonicity audit verifying 1,568 demographic permutations, proving that smoking status never spuriously decreases estimated charges (minimum smoker delta: +9,981.18 USD). The trained pipeline is serialized into an atomic scikit-learn artifact ensuring zero train-serve skew, backed by statistical confidence bounds (± MAE) and an interactive counterfactual "What-If" engine.

3. Theoretical Foundations & Baseline Benchmarks

3.1 Multiple Linear Regression & Ordinary Least Squares (OLS)

The classical supervised linear regression hypothesis is formulated in matrix notation as:
y = Xw + ε
where X ∈ Rn × (d+1) is the design matrix (including intercept column 1), w ∈ Rd+1 is the parameter vector, and ε ∼ N(0, σ2 I) represents unobserved i.i.d. Gaussian error residuals.

The Ordinary Least Squares objective minimizes the Sum of Squared Residuals (SSres):

J(w) = ||y - Xw||22 = (y - Xw)T(y - Xw)

Setting the gradient vector with respect to w to zero yields the Normal Equation:

∇w J(w) = -2XT(y - Xw) = 0
XTXw = XTy ⇒ w* = (XTX)-1XTy

3.2 Regularized Ridge Regression (L2 Penalty)

To stabilize matrix inversion when multicollinearity exists, Ridge regression introduces an L2 weight shrinkage penalty:
JRidge(w) = ||y - Xw||22 + α ||w||22 ⇒ w*Ridge = (XTX + α I)-1XTy

3.3 Why Linear Models Fail on Actuarial Medical Data

When trained on the 80% partition of insurance.csv:
  • OLS Linear Regression yields holdout R2 = 0.7836 and MAE = 4,181.19 USD.
  • Ridge Regression (α = 1.0) yields holdout R2 = 0.7833 and MAE = 4,193.20 USD.

Both linear baselines severely fail the course quality benchmarks (R2 < 0.85 and MAE > 2,000 USD). The failure stems from residual bias: linear hyperplanes cannot approximate step-function interactions (BMI ≥ 30 × smoker), resulting in large systematic residuals across obese smokers and healthy non-smokers alike.

5. Proposed Methodology: Regularized CART Decision Tree Regressor

5.1 Algorithmic Foundations of CART

The Classification and Regression Trees (CART) algorithm, pioneered by Breiman et al. (1984), recursively partitions the feature space X into M disjoint hyper-rectangles {R1, R2, …, RM}. Within each terminal region Rm, the hypothesis predicts a constant actuarial value ĉm:
ŷ = h(x) = ∑m=1..M ĉm ⋅ I(x ∈ Rm)

At each node, CART performs a greedy search to determine the optimal split variable j and split threshold s dividing the data into half-planes R1(j, s) = {x | xj ≤ s} and R2(j, s) = {x | xj > s}.

5.2 Splitting Criteria: L2 (Mean) vs. L1 (Median) Loss & Probabilistic Interpretation

A critical algorithmic decision in regression trees is the choice of impurity criterion. This can be understood rigorously through Maximum Likelihood Estimation (MLE):
  1. Mean Squared Error (L2 Loss — criterion="squared_error"):
Qm(T) = 1|Rm|∑i ∈ Rm (yi - ȳm)2,   where ȳm = 1|Rm|∑i ∈ Rm yi
  • Probabilistic Origin: Minimizing L2 loss is mathematically equivalent to Maximum Likelihood Estimation under the assumption of additive Gaussian noise: εi ∼ N(0, σ2). The negative log-likelihood is LNLL ∝ ∑ (yi - ŷi)2. Setting the derivative to zero yields the conditional sample mean ȳm.
  • Limitation on Healthcare Data: Medical claims distributions exhibit severe positive skew with heavy tails (e.g., catastrophic hospitalization events exceeding $60,000). Because errors are squared, extreme outliers dominate the loss gradient, pulling split thresholds and leaf predictions upward and artificially inflating quotes for healthy policyholders.
  1. Mean Absolute Error (L1 Loss — criterion="absolute_error"):
Qm(T) = 1|Rm|∑i ∈ Rm |yi - ĉm|,   where ĉm = median({yi | xi ∈ Rm})
  • Probabilistic Origin: Minimizing L1 loss corresponds directly to MLE under an additive Laplace (double-exponential) noise distribution: εi ∼ Laplace(0, b) with probability density function p(ε) = 12bexp(-|ε|b). The negative log-likelihood is LNLL ∝ ∑ |yi - ŷi|. Differentiating with respect to ĉm yields ∑ sgn(yi - ĉm) = 0, whose solution is the conditional sample median.
  • Actuarial Advantage: The conditional median is highly resistant to outlier contamination. In DeltaCare, L1 optimization guarantees that catastrophic claims do not distort standard plan estimates, achieving an audited holdout MAE of $1,749.60.

5.3 Regularization Hyperparameters

Unconstrained decision trees grow until every leaf is pure, memorizing noise and training samples. To regularize the hypothesis, we enforce:
  • max_depth = 6: Constrains the maximum tree depth to 6 levels (M ≤ 26 = 64 leaves), preventing complex, high-variance decision surfaces.
  • min_samples_leaf = 10: Guarantees that every leaf contains at least 10 historical training instances, ensuring statistical validity and eliminating spurious split anomalies.
  • random_state = 42: Ensures 100% deterministic reproducibility.

8.2 Discovery & Resolution of the Monotonicity Defect

During pull request automated review (PR #23), an actuarial edge-case was flagged: with min_samples_leaf=5, an under-regularized leaf split caused a 20-year-old Northwest male with BMI 24 and 2 children to be priced higher after quitting smoking (Smoker = $16,450.89, Non-Smoker = $18,838.70, Delta = -$2,387.81).

Root Cause: With a leaf support floor of only 5 samples, an atypical cluster of hospitalized young non-smokers in the Northwest formed an isolated high-cost leaf node.

Resolution & Empirical Audit: Increasing min_samples_leaf=10 eliminated spurious leaf partitions. We authored an exhaustive automated audit in scripts/audit_model.py evaluating 1,568 demographic combinations:

  • Dependents: [0, 1, 2, 3]
  • Sexes: [male, female]
  • Regions: [northeast, northwest, southeast, southwest]

Audit Results:

  • Monotonicity Violations: 0 defects across all 1,568 profile pairs.
  • Minimum Smoker Premium Delta: +$9,981.18 (Smoking is strictly penalized across every demographic).

9. Real-Time Inference, Uncertainty Bounds & Guardrails

9.1 Mathematical Clamping Floor

Raw regression outputs on extreme edge cases can mathematically yield unrealistic or negative values. DeltaCare enforces an actuarial minimum floor in the inference pipeline:
Premiumannual = max(1000.00, ŷ)
Premiummonthly = Premiumannual12

9.2 Statistical Confidence Bounds

Traditional quotes provide deceptive single-point estimates. DeltaCare bounds every prediction with the holdout validation Mean Absolute Error (MAE = 1,749.60 USD):
Confidence Interval = [max(1000.0, ŷ - MAE), ŷ + MAE]
Monthly Interval = [CIlower12, CIupper12]

9.3 Counterfactual What-If Analysis

For individuals with smoker = "yes", DeltaCare computes an on-the-fly counterfactual prediction ŷcf = h(x | smoker=no), rendering an instant quantifiable incentive:
Δsavings = max(0, ŷsmoker - ŷnon-smoker)
